# 🛒 The Retail Psychology & Live API Simulator

A responsive educational web application that demonstrates common e-commerce psychology techniques using live product data from the DummyJSON API. Users can interact with features like scarcity countdowns, hidden fees, and low-stock alerts while observing their impact on pricing and consumer behavior.

## ✨ Features
- Live product data from DummyJSON API
- Random product on every refresh
- Scarcity countdown timer
- Drip pricing simulation
- Artificial low-stock alerts
- Real-time price calculation
- Behavioral analysis panel
- Responsive Bootstrap design

## 🛠️ Tech Stack
- HTML5
- Bootstrap 5
- Vanilla JavaScript (ES6)
- Fetch API
